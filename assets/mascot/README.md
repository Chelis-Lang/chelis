# Chev Chelis

The Chelis project mascot.

**Name:** Chev Chelis (Chev for short)

**What:** A turtle riding a mountain bike up a steep hill.

**Motto:** *"Hill climbing is its own reward."*

**Accessories:** Round glasses, red racing headband, blue sneakers, sports watch.

## Files

- `chev.svg` — the mascot SVG
- `generate_chev.py` — Python script that produces `chev.svg`
