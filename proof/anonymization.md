# Anonymization Checklist

POPL is double-blind. Run through this list before submission. Owned by WS6 but separated for visibility.

- [ ] No author names or affiliations in paper or supplementary material
- [ ] Own work referenced in third person
- [ ] No acknowledgments section
- [ ] Lean code: no names, no institutional paths, no git history, no identifiable URLs
- [ ] BibTeX: own publications anonymized
- [ ] Supplementary PDF: clean metadata
- [ ] HotCRP: conflicts declared
- [ ] TPMS: reserve reviewer registered with 5–10 papers
