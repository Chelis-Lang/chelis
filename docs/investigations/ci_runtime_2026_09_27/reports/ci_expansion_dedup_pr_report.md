## Why the optimization was stopped

The exact-candidate #2586 artifacts show **57** standing Fast integration targets in manual expansion and **466** matching test identities. Identity alone does not establish the same Cargo execution configuration. Fast's selector runs 94 of the 97 current standing targets in a single `--workspace --lib --bins --test ...` invocation; manual expansion runs package-scoped `-p` groups. On this branch, `cargo tree -e features` reports different resolved package/dependency feature closures for **all 12 packages** containing standing targets. A normal two-package resolver-2 fixture reproduced the semantic risk: workspace Fast listed `common`, while package-scoped expansion listed `common` and a `#[cfg(not(feature="extra"))]` `default_only` case. Blindly omitting by Fast test name would silently drop that case.

Fast separately uses package-scoped selections for three collision-name standing targets. In #2586, two of those enter manual expansion: `chelis-cli::issue_1955_grad_selector_identity` (5 cases) and `chelis-surf::issue_1955_grad_selector_identity` (17). Their Fast/manual commands use the same `-p` package and no extra features. Their **22** test bodies took **0.73 seconds combined** in the sampled JUnit (0.61s CLI, 0.12s Surf). The third package-scoped target was not selected manually. Thus the sound route would save at most 22 of the 466 cases, with under one second of measured test body work. It does not touch the 28.9-minute bindings census or 17.8-minute wire census that dominate manual expansion. A roughly 700-line cross-workflow authorization/receipt mechanism is disproportionate to that benefit.

Recommendation: prioritize the separate package-expansion sharding/baseline repair (#2678). If broader dedup is revisited, first decide whether standing Fast and manual expansion should use the *same Cargo package/feature selection* and preserve or intentionally replace the current package-scoped coverage claim. Measure end-to-end wall-clock effect before adding omission machinery. Report matching test IDs as same-named overlap unless feature equivalence is proved.
