# Docs Archive

Point-in-time documents live here so top-level `docs/` stays focused on active runbooks
and current status.

- `perf/`: dated performance baselines and investigations
- `rca/`: root-cause analysis reports
- `red-team/`: red-team sweeps and validation reports
- `reports/`: generated or one-off project reports
- `snapshots/`: repository snapshots and archaeology
