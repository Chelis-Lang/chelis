# Archived investigations

These are diagnosis notes, review records, and workstream audits whose subject is
resolved. They are kept because code comments, tests, or other records cite them.
Each note describes the code as it was when the note was written; file paths, line
numbers, issue states, and conclusions may no longer match the current tree. They are
not current behavior: the numbered chapters in [`spec/`](../../../spec/) own the
language contract, and open work lives in the GitHub issue tracker.

Investigations whose subject is still open stay in
[`docs/investigations/`](../../investigations/).
