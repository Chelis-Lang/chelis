A compiled C artifact built from a package entry module now prints the same output as `chelis eval`. It prints only the roots the entry module declares; previously it also printed top-level values and zero-argument definitions from chelis-std, path dependencies, and the package's other modules. It renders every data-type constructor by its source name, such as `Point(1.0, 2.0)`; previously a package data type printed under its internal package-qualified name. See [#2624](https://github.com/Chelis-Lang/chelis/issues/2624) and [#2880](https://github.com/Chelis-Lang/chelis/issues/2880).
