`len` and `index` read a container that is already borrowed, such as a `&List[T]` or `&Dict[K, V]` parameter, on the checker, the evaluator and compiled C, and the caller keeps the container it lent. Previously the checker refused every such query as if the source had written the explicit `len(&xs)`. That explicit spelling stays refused, at a direct call and through a function value (`f = len; f(&xs)`). See [#3403](https://github.com/Chelis-Lang/chelis/issues/3403).
