In a reef package module, a `def` or `sig` named like a standard prelude macro (`residual`, `linear_layer`, `cross_entropy`) is now rejected by `chelis check` and `chelis build` as well as by `chelis eval`, with the spec/02 §P5b diagnostic naming the declaration as written. Previously `check` reported the package clean and `build` produced a binary that called the `def` in place of the macro; the rule now holds in every module of a package, including modules the checked file imports. See [#3270](https://github.com/Chelis-Lang/chelis/issues/3270).
