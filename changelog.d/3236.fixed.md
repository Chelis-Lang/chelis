`chelis prove` no longer certifies a false property whose binder or module name is spelled like a solver symbol the prover generates, such as `__erf_abs_0`, `__contract_std_normal_cdf_0`, or `__contract_std_quantile_0`. Generated symbols are now chosen fresh against every name in the goal, so such a name stays an independent variable and the property is refuted or left unsupported; a counterexample may show the generated symbol with a numeric suffix. A solver goal that declares one variable twice is rejected instead of merging the two variables into one. See [#3236](https://github.com/Chelis-Lang/chelis/issues/3236).
