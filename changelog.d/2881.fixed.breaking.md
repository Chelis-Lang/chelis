A `.ch` file outside every reef package now resolves its `import Std.*` declarations against the compiler-bundled `chelis-std` in `chelis eval`, `check`, `build`, `cost`, and `prove`, under the same binding and collision rules as a package module. Previously the imports were silently dropped: an import of a nonexistent module was accepted, an imported name stayed unbound, and a builtin of the same name could stand in for the imported definition. An import of a module that does not exist is now an error naming the module, and an import of a module outside `chelis-std` is an error saying a `reef.toml` package manifest is needed. See [#2881](https://github.com/Chelis-Lang/chelis/issues/2881).
