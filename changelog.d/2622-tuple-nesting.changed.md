Type checking a program with deeply nested types, such as a chain of nested tuples, no longer copies each node's type, so its time and memory grow linearly with the nesting depth instead of quadratically. A tuple chain 4,000 deep took 22.4G instructions and about 1 GB of memory to check, and now takes 2.6G and 156 MB. Checker output is unchanged. See [#2622](https://github.com/Chelis-Lang/chelis/issues/2622).
