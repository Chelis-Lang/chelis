Runtime, CLI and Python builds now retain canonical runtime compatibility records and explicit source-worktree or sealed-distribution provenance. Source builds require observer-managed Cargo through Devenv or `scripts/runtime_identity_build.py`; missing or stale required observations fail the build. A data-only identity core and shared build adapter support Cargo and separate Nix producers, with strict native record decoding and dedicated producer acceptance. Runtime selection is unchanged: this producer-only work does not establish installed-package acceptance or resolve [#1354](https://github.com/Chelis-Lang/chelis/issues/1354).
