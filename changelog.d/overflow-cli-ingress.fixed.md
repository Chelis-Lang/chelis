Deep inputs accepted by `chelis check` no longer abort `chelis eval`, `chelis cost`, or `chelis build` on the reported nested application chains. Nested Surf calls also reach the build pipeline without exhausting the CLI's main stack. See [#2610](https://github.com/Chelis-Lang/chelis/issues/2610), [#2614](https://github.com/Chelis-Lang/chelis/issues/2614), and [#2897](https://github.com/Chelis-Lang/chelis/issues/2897).
