A declared result extent that the body refutes once a call is inlined is now rejected before the program runs, instead of executing with the undeclared shape, trapping for a comparison that could never hold, or failing an internal IR invariant on the C lane. `chelis eval` and `chelis build` report the same diagnostic and exit 1. The rule covers a literal claim, a named claim whose declaring argument is itself fixed, an axis an operation leaves unchanged, and activations reached through a pipe or a `vmap`. A claim whose extent is only known at run time keeps its existing runtime guard (chelis#1837, chelis#1930).
