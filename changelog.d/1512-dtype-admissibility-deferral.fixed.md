The dtype-admissibility checks now run against the operand a call actually receives. A builtin whose operand was still an unresolved type variable when its route ran skipped those checks forever, so `sqrt`, `and`, `add`, `mean`, `softmax`, `uniform_like`, the integer binary operators and the shifts each accepted a program they reject when the same operand is written out directly. The call is suspended on the deferred shape ledger instead and validated once the operand binds, with the diagnostic a resolved operand gives. An operand that never binds stays accepted: these routes do not require a shape, so a genuinely generic definition is unaffected.
