CI authenticates pinned Bullseye indexes through the official Cloudflare snapshot endpoint. Debian Archive supplies package bytes only after verification against the signed index size and SHA-256. The private worker preserves process-group termination when a child ignores SIGTERM. The snapshot, package versions, signature policy, and retry limits stay unchanged. See [#4117](https://github.com/Chelis-Lang/chelis/issues/4117).
