Checker rejections for tensor conversion, copy, cast, expand, shrink, reshape, stride, pad, window reductions, contraction axes, reduction inputs and axes, diagonal result extents and repeated axes, gradient selector bounds and metadata contradictions, application and callback arity, and declared precision now report the available source location and directional `expected`/`got` operands where known. Imported function-call mismatches name the source module and function rather than the linker's private symbol. Symmetric inferred-operand conflicts retain no invented direction. Declared return and ascription mismatches carry the declared and inferred types. Duplicate definitions point to the redeclaration where its source location is available. Unresolved-type admission remains unchanged. See [#1334](https://github.com/Chelis-Lang/chelis/issues/1334).
