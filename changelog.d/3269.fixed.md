Diagnostics from `chelis check`, `chelis eval` and `chelis build` in a reef package now name declarations and types as the author wrote them (`def 'out'`) instead of by the package linker's private `pkg__<package>__<Module>__<name>` spelling, so a package module and a standalone file report the same text. Authored names containing `__` are shown whole. See [#3269](https://github.com/Chelis-Lang/chelis/issues/3269).
