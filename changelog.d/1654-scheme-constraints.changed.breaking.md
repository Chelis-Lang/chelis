`chelis_types::Scheme` gains a public `constraints: Vec<CollectionConstraint>` field, so direct struct literals must supply it; `Scheme::mono` is unchanged. `TYPE_ENV_FORMAT_VERSION` advances from #2071's version 2 to version 3. Older checker snapshots are rejected instead of silently restoring checked collection function values without their contracts. See [#1654](https://github.com/Chelis-Lang/chelis/issues/1654).
