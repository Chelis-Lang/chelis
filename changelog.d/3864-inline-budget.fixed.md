`chelis cost` no longer runs out of memory on a recursion that calls itself in both arms of a branch whose condition is known only at runtime, such as a bisection root finder. Tensor-DAG lowering now rejects an unroll once one of its frames makes more than one recursive call back into its own recursion and the unroll has inlined 32,768 function bodies; the diagnostic names the recursion. A chain-shaped unroll is never limited, including a static loop, an early-exit loop, a mutual recursion of one call per level, and loops nested or run one after another inside a loop. The existing unroll depth limits bound it. After a rejection the program falls back to host lowering, as it does for the depth limits, and `cost` omits the rejected entry, as it does for an entry that exceeds a depth limit.
