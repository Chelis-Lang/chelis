`chelis cost` no longer runs out of memory on a recursion that calls itself in both arms of a branch whose condition is known only at runtime, such as a bisection root finder. Tensor-DAG lowering now rejects an unroll that recurses inside a runtime branch once it has inlined 32,768 function bodies, and the diagnostic names the recursion. An unroll that never recurses inside a runtime branch is not counted; the existing unroll depth limits bound it. After a rejection the program falls back to host lowering, as it does for the depth limits, and `cost` omits the rejected entry, as it does for an entry that exceeds a depth limit.
