`chelis cost` no longer runs out of memory on a recursion that calls itself in both arms of a branch whose condition is known only at runtime, such as a bisection root finder. Tensor-DAG lowering now inlines at most 32,768 function bodies in one recursion's unroll. A body counts only while some function is recursing, so inlining non-recursive helpers never counts. An unroll past the budget is rejected with a diagnostic that names the recursion, and the program then falls back to host lowering, as it does for the existing unroll depth limits.
