`chelis cost` no longer runs out of memory on a recursion that calls itself in both arms of a branch whose condition is known only at runtime, such as a bisection root finder. Tensor-DAG lowering now inlines at most 32,768 recursive calls in one recursion's unroll. Only a call to a function already being inlined counts, so a non-recursive helper never counts, however large it is. An unroll past the budget is rejected with a diagnostic that names the recursion. The program then falls back to host lowering, as it does for the existing unroll depth limits, and `cost` omits the rejected entry, as it does for an entry that exceeds a depth limit.
