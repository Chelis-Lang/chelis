Published package metadata now records checked collection relations. `chelis_shell::ShellSymbol` gains `collection_obligations: Vec<CollectionObligation>`, CHB advances from #2071's format 4 to format 5, and `reef schema` advances from format 2 to format 3. Each relation names `len`, `index`, `append`, or `concat` and carries canonical Deep operand/result types under variables already present in the exported callable type; ledgers are strictly ordered and unique, and hidden variables are rejected. Public decoders reject predecessor and unknown versions rather than reading them as unconstrained. CHB and Reef schema protect publication identity; serialized TypeEnv owns compiler checker reuse. See [#1654](https://github.com/Chelis-Lang/chelis/issues/1654).
