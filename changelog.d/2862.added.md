`Std.Datetime.Zone` adds time zone rules as values. `time_zone_from_tzif` reads a TZif file (RFC 9636, versions 2 to 4) from bytes the program supplies, including its POSIX TZ footer rule; `time_zone_fixed` and `time_zone_utc` build fixed zones. `Zoned` values convert local readings with a required `Disambiguation` (`EarlierInstant`, `LaterInstant`, `CompatibleInstant`, `RejectNonUniqueLocal`) for daylight saving gaps and folds, add durations on the instant line and periods on the wall clock, and read and write RFC 9557 text, resolving a written offset with a required `OffsetConflict` policy. A zone whose footer is empty fails `domain` from its last transition on instead of extrapolating. See [#2862](https://github.com/Chelis-Lang/chelis/issues/2862).
