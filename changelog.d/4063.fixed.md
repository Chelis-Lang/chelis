Reef remote discovery downloads a release's source archive only when resolution
selects that release. An exact requirement downloads one archive, and a range
downloads the newest matching release unless resolution has to walk back past
it, so an anonymous `chelis reef build` of a package with many releases no
longer exhausts GitHub's 60-request anonymous limit. When GitHub's rate limit
still refuses a discovery request, the error says whether the anonymous or the
token's limit was exhausted and names `chelis reef install --from-github
<org>/<repo>@<tag>` as a way to install without discovery. See
[#4063](https://github.com/Chelis-Lang/chelis/issues/4063).
