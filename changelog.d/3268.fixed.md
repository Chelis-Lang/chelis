`chelis build` for C, HIP and Metal now rejects a call through a function value that a `match` pattern bound, such as a function stored in a constructor payload, a record field or an `Option`, with the typed `unsupported:` diagnostic that names the C target and cites [#879](https://github.com/Chelis-Lang/chelis/issues/879). Previously the build failed inside ownership lowering with a message naming a compiler-generated binder such as `__chelis_pattern_h__inl1`. `chelis eval` still runs these programs. See [#3268](https://github.com/Chelis-Lang/chelis/issues/3268).
