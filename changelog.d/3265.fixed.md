Compiled C now evaluates the fields of a by-name record literal in written order, as `chelis eval` does, when that order differs from the type's declared field order. Previously the C lane evaluated them in declared order, so a program such as `S { hi: index(xs, 5), lo: index(xs, 7) }` trapped on the field declared first rather than the field written first, and field effects such as `debug` printed in a different order than in `eval`. Field values are still stored in declared order. See [#3265](https://github.com/Chelis-Lang/chelis/issues/3265).
