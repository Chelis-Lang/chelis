`uniform_like` now draws the [05-RNG-1] counter stream in every lane: `chelis eval`, the DAG evaluator, compiled C (including the host code of Metal builds) and HIP. Element `i` of the draw with call ordinal `c` comes from the word `splitmix64(seed_bits ^ rotl64(splitmix64(c), 17) ^ rotl64(splitmix64(i), 41))`, the stream `dropout` already used. The previous mixing combined the ordinal and the index symmetrically, so element `i` of draw `c` equalled element `c` of draw `i`, and element `c` of draw `c` was the same value for every `c`.

Every `uniform_like`-derived value changes for a given seed, including `normal_like`, `trunc_normal`, the Kaiming and Xavier initialisers, and library distributions built on them; regenerate any pinned random outputs. `dropout` masks are unchanged. In the Rust API, `chelis_types::uniform_sample` now takes the draw key from the new `chelis_types::random_draw_key(seed_bits, ordinal)` where it took a premixed seed. See [#2408](https://github.com/Chelis-Lang/chelis/issues/2408).
