`Std.Datetime.Clock` reads the host clocks. `clock_now()` returns the wall-clock
`Instant`, and `monotonic_now()` returns an opaque `MonotonicInstant` from a
clock that never runs backwards. `monotonic_until(a, b)` is the exact `Duration`
from `a` to `b`. It is the only operation on a `MonotonicInstant`, which does
not convert to an `Instant`. Both reads carry `IO`, so a caller declared
without `IO` cannot call them. A failed read reports
`clock_wall_read: io: <detail>` or `clock_monotonic_read: io: <detail>`, naming
the underlying builtin. The module is separate from `Std.Datetime`, so a program
that imports only `Std.Datetime` never reads a clock. `chelis eval` and
`chelis test` run the clocks; compiled builds reject them until compiled host
execution lands ([#1297](https://github.com/Chelis-Lang/chelis/issues/1297)).
See [#2863](https://github.com/Chelis-Lang/chelis/issues/2863).
