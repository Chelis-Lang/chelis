`chelis build` compiles a bare `[]` passed as an argument whose element type is
a dimension-generic ADT, such as the accumulator of a recursive
`def repl[n](xs: List[Col[n]], acc: List[Col[n]])`, as `chelis check` and
`chelis eval` already accepted. An argument staged for an inlined call took its
type from the lowered actual alone, so a context-fixed nullary actual kept an
inference hole and the program failed with "unresolved host inference variable";
the staged actual now takes the formal's resolved type. A type-generic ADT, a
non-generic ADT and a bare `tensor[n, f32]` element already compiled, so only
the dimension beneath the ADT was affected. An empty list whose element type
nothing fixes is still rejected with the same diagnostic. This unblocks twelve
`Coral.Frame` verbs, including `drop_nan`, `filter`, `head`, `slice`, `sort_by`
and `with_column`. See
[#3153](https://github.com/Chelis-Lang/chelis/issues/3153) and
[Chelis-Lang/coral#26](https://github.com/Chelis-Lang/coral/issues/26).
