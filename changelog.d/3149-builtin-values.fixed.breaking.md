A builtin is now a function value only when its whole operation rule travels with the value: `len`, `index`, `append`, `concat`, `fold`, `scan`, the key builtins, and the builtins whose type signature states their rule completely. Every other builtin is applicable only by name. Binding it (`op = sum`), passing it as an argument or as a `map`, `fold`, `vmap` or `grad` callback, placing it in a list or tuple, or returning it is now a `TypeMismatch` that names the builtin and suggests an explicitly typed lambda that calls it. Such programs previously passed `chelis check` with result types the operation never produces, for example an aliased `sum` declared to return `i8` or an aliased `lt` declared to return `f32`, and no execution lane ran them. See [#3149](https://github.com/Chelis-Lang/chelis/issues/3149).
